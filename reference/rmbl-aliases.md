# The 0.5.x names, kept as aliases

Every function rmoriebricklayer 0.5.13 exported that 1.0.0 renamed is
still callable by its old name, with its old argument names: each alias
forwards to the new function. The reference documentation lives on the
new name; this page only lists the aliases.
