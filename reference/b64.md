# Base64 encoding

Encodes and decodes base64, in both the standard alphabet and the
URL-safe variant. Computed in R with no dependency, so a capsule can
embed binary content in a text manifest wherever this package runs.

## Usage

``` r
jsb64enc(input)

jsb64dec(input)

jsb64uenc(input)

jsb64udec(input)
```

## Arguments

- input:

  For the encoders, a raw vector, or a character vector (its elements
  are joined with newlines and encoded as UTF-8 bytes), or `NULL`. For
  `jsb64dec()`, base64 text (a character vector, joined with newlines)
  or its raw bytes. For `jsb64udec()`, URL-safe base64 text, with or
  without `=` padding.

## Value

The encoders return a character scalar (`""` for empty input,
`NA_character_` for `NULL`); the decoders return a raw vector (use
[`rawToChar()`](https://rdrr.io/r/base/rawConversion.html) for text).

## Details

`jsb64enc()` breaks its output into 72-character lines (a newline after
each complete block of 54 input bytes), matching jsonlite's encoder byte
for byte; the decoder ignores line breaks, other white space and `=`
padding, so either form round trips. Any other character outside the
alphabet is an error rather than being skipped, because skipping it
would decode a corrupted body into a shorter valid-looking one.

The URL-safe variant substitutes `-` and `_` for `+` and `/` and drops
the `=` padding, which is what makes it safe in a URL path, a query
string or a filename.

Base64 is an ENCODING, not encryption or a digest: it hides nothing and
anyone can reverse it. Use
[`csha256()`](https://rootcoder007.github.io/rmorie-bricklayer/reference/csha256.md)
to pin content and
[`chmac()`](https://rootcoder007.github.io/rmorie-bricklayer/reference/keyeddgst.md)
to authenticate it.

Errors: an encoder given anything but a raw vector, a character vector
or `NULL`; `jsb64dec()` given anything but text or raw bytes, or text
with a character outside the standard alphabet; `jsb64udec()` given
anything but character text (raw bytes are refused), `NA`, or a
character outside the URL-safe alphabet.

## See also

[`jsgzenc()`](https://rootcoder007.github.io/rmorie-bricklayer/reference/jsgz.md),
which composes this with gzip.

## Examples

``` r
# Round trip through the standard alphabet.
b <- jsb64enc("hello capsule")
b
#> [1] "aGVsbG8gY2Fwc3VsZQ=="
rawToChar(jsb64dec(b))
#> [1] "hello capsule"

# Raw input works the same way.
jsb64enc(charToRaw("abc"))
#> [1] "YWJj"
jsb64dec(jsb64enc(charToRaw("abc")))
#> [1] 61 62 63

# Padding appears when the length is not a multiple of three.
jsb64enc("a")
#> [1] "YQ=="
jsb64enc("ab")
#> [1] "YWI="
jsb64enc("abc")
#> [1] "YWJj"

# The URL-safe variant has no "+", "/" or "=" to escape.
jsb64uenc(as.raw(c(255, 224, 63)))
#> [1] "_-A_"
jsb64enc(as.raw(c(255, 224, 63)))
#> [1] "/+A/"
jsb64udec(
  jsb64uenc("path/safe?yes")
)
#>  [1] 70 61 74 68 2f 73 61 66 65 3f 79 65 73

# Long input is wrapped, and the decoder ignores the breaks.
long <- jsb64enc(strrep("x", 200))
grepl("\n", long)
#> [1] TRUE
rawToChar(jsb64dec(long)) == strrep("x", 200)
#> [1] TRUE

# A character outside the alphabet is refused, not skipped.
try(jsb64dec("ab$c"))
#> Error : base64 input contains characters outside the alphabet
```
